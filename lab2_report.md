# Лабораторная работа №2

## "Эмуляция распределённой корпоративной сети связи, настройка статической маршрутизации между филиалами"

Университет: Университет ИТМО
Факультет: Инфокоммуникационных технологий
Курс: Введение в маршрутизацию

---

## Цель работы

Ознакомиться с принципами планирования IP-адресов, настройкой статической маршрутизации и сетевыми функциями устройств.

---

## Описание

Компания "RogalKopita Games" LLC занимается разработкой мобильных игр и имеет офисы в трёх городах: Москве, Франкфурте и Берлине. Для обеспечения связи между офисами необходимо установить 3 роутера, настроить IP-адресацию и поднять статическую маршрутизацию. В результате сотрудники из любого офиса должны иметь возможность обмениваться данными с сотрудниками других офисов.

---

## Схема сети

```
                         PC3
                          | (ether3)
                      R01.BRL
                     (Берлин)
                    /         \
       (ether1/ether1)    (ether2/ether1)
                  /               \
   R01.MSK ─────────────── R01.FRT
  (Москва)   (ether2/ether2)   (Франкфурт)
      |                          |
     PC1                        PC2
   (ether3)                   (ether3)
```

## Вывод

В ходе лабораторной работы была развёрнута сеть из трёх роутеров MikroTik, соединяющих офисы компании "RogalKopita Games" в Москве, Франкфурте и Берлине. На каждом роутере настроены:

1. IP-адреса на всех интерфейсах
2. DHCP-серверы для автоматической выдачи адресов клиентским ПК
3. Статические маршруты для обеспечения связности между всеми подсетями

Все пинги между офисами проходят успешно (0% потерь), связность полная. Сотрудники из любого офиса могут обмениваться данными с сотрудниками из двух других офисов.
